# Лабораторная 2. Текстовый калькулятор

**Максимум:** 10 баллов (база 6 + дополнительные задания сложностью не менее 4).

Нужно написать функцию `calc(expr: str) -> str`, которая вычисляет выражение, записанное **словами**, и возвращает результат тоже словами. Консольная обёртка читает строку, вызывает `calc` и печатает ответ либо сообщение об ошибке. Программа не должна завершаться из-за некорректного ввода.

Нельзя решать задачу вызовом `eval` / `exec` и аналогичных функций для произвольного кода.

Запуск: `python3 2lab/main.py` из корня репозитория.

Вариант: `(номер зачётной книжки % 4) + 1`.

Числа в примерах ниже — неотрицательные, если в выбранных дополнительных пунктах не сказано иное. Числовые слова — русские, в именительном падеже, как в примерах (допускается разумная нормализация пробелов).

## Чему учимся: цикл и рекурсия

Разбор строки словами — это **цикл** по токенам (как проход по слагаемым суммы).

Вложенность — это **рекурсия**: скобка или «внутренняя» операция считается так же, как вся формула, только на более коротком куске. В математике это подстановка: сначала посчитали скобку, потом подставили. В экономике — сначала внутри периода, потом агрегация.

Обязательно:

- слова выражения обходятся циклом (не вызывать `eval`);
- если берёте дополнительные пункты про **несколько операций** или **скобки**, разбор сделать **рекурсивным спуском** (функция вызывает себя на части выражения). Стек допустим как вспомогательная структура, но на защите нужно уметь нарисовать рекурсивный вариант.

Лекции: [01 — Python как математика](../lectures/01-python-kak-matematika.pptx), [05 — Рекурсия](../lectures/05-rekursiya.pptx).

## Вариант 1. Длительности

**Базовое задание.** Выражение вида `<длительность> <операция> <длительность>`. Длительность — часы и/или минуты словами. Операции базового уровня: `плюс`, `минус`. Результат нормализуется: минуты в диапазоне 0–59, часы неотрицательные.

```
calc("два часа пятнадцать минут плюс сорок минут") -> "два часа пятьдесят пять минут"
calc("один час минус десять минут") -> "пятьдесят минут"
```

Нулевые единицы в ответе не выводятся (`"пятьдесят минут"`, а не `"ноль часов пятьдесят минут"`), кроме нулевого результата: `"ноль минут"`.

Диапазон базового задания: часы 0–23, минуты 0–59. Отрицательный результат — ошибка.

## Вариант 2. Деньги

**Базовое задание.** Суммы в рублях и/или копейках. Операции: `плюс`, `минус`. Ответ нормализуется: копейки 0–99, корректные окончания (`рубль` / `рубля` / `рублей`, `копейка` / `копейки` / `копеек`).

```
calc("три рубля пятьдесят копеек минус один рубль двадцать копеек") -> "два рубля тридцать копеек"
calc("девяносто девять копеек плюс две копейки") -> "один рубль один копейка"
```

Для `"один рубль один копейка"` допустим грамматически верный вариант `"один рубль одна копейка"`. Нулевой результат: `"ноль рублей"`. Отрицательный результат — ошибка.

Диапазон базового задания: рубли 0–99, копейки 0–99.

---

## Вариант 3. Меры длины

**Базовое задание.** Длины в метрах и/или сантиметрах. Операции: `плюс`, `минус`, `умножить` (второй операнд — целое число словами, не длина). Ответ нормализуется: сантиметры 0–99.

```
calc("два метра тридцать сантиметров умножить на три") -> "шесть метров девяносто сантиметров"
calc("один метр минус сорок сантиметров") -> "шестьдесят сантиметров"
```

Нулевой результат: `"ноль сантиметров"`. Отрицательный результат — ошибка.

Диапазон базового задания: метры 0–99, сантиметры 0–99, множитель 1–20.

---

## Вариант 4. Логика

**Базовое задание.** Выражение из констант `истина` / `ложь` и ровно одной бинарной операции `и` или `или`, либо унарной `не` перед одной константой.

```
calc("истина и ложь") -> "ложь"
calc("ложь или истина") -> "истина"
calc("не истина") -> "ложь"
```

Приоритет в базовом задании не требуется: в выражении ровно одна операция (унарная или бинарная).

5. Операция `разделить на` целое число с отбрасыванием остатка до целых секунд (если секунд нет — до целых минут). Деление на ноль — ошибка.
