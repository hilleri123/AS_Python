# Презентации

На пару удобнее **PPTX** (PowerPoint, LibreOffice Impress, Google Презентации). HTML — запасной вариант в браузере.

| PPTX | HTML | Когда показывать |
|---|---|---|
| [00-organizaciya.pptx](00-organizaciya.pptx) | [html](00-organizaciya.html) | первая пара: сдача, git, таблица, pytest |
| [01-python-kak-matematika.pptx](01-python-kak-matematika.pptx) | [html](01-python-kak-matematika.html) | 1–2 недели: задача ЕГЭ → бланк → Python; строки; дата |
| [02-cikly.pptx](02-cikly.pptx) | [html](02-cikly.html) | к лабораторной 1: `for` как сумма, `while` как «пока» |
| [03-rekursiya.pptx](03-rekursiya.pptx) | [html](03-rekursiya.html) | к лабораторным 2 и 4: рекуррентность, дно, стек |

Формат слайдов — 16:9. Схема сдачи: [scheme-sdacha.png](scheme-sdacha.png).

HTML: открыть в браузере, `F11` — полный экран, стрелки листают. Интернет не нужен.
