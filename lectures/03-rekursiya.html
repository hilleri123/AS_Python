Рекурсия

Рекуррентность, начальное условие, подстановка в себя. Не «магия», а способ записать an через an−1.

Уже знакомо

Рекуррентное соотношение

a1 = 100
an = an−1 · (1 + r)

Чтобы узнать a4, вы не придумываете новый мир. Вы сводите вопрос к a3, тот — к a2, пока не упрётесь в a1.

Это и есть рекурсия: функция считает свой случай, вызывая себя на более коротком.

Экономика

Сложный процент — рекурсия в одну строку

def capital(n, start, rate):
    if n == 0:
        return start
    return capital(n - 1, start, rate) * (1 + rate)

n == 0 — начальное условие. Без него ряд не определён, функция не остановится.

Ещё один канон

n! вы и так определяете рекурсивно

0! = 1
n! = n · (n − 1)!

def fact(n):
    if n == 0:
        return 1
    return n * fact(n - 1)

Перевод дословный. Кто пишет fact циклом — тоже прав; рекурсия здесь про ясность определения.

Две части

Без дна рекурсия — дырявая модель

Базовый случай

Когда задача слишком маленькая, чтобы делить: n = 0, пустая скобка, некуда прыгать.

Шаг

Как свести текущее к такому же, но проще: n → n−1, скобка → внутренность, клетка → следующая.

На защите спрашивают оба. «Оно само» — не ответ.

Что происходит

Стек — столбик подстановок

Считаем fact(3):

fact(3) = 3 * fact(2)
        = 3 * (2 * fact(1))
        = 3 * (2 * (1 * fact(0)))
        = 3 * (2 * (1 * 1))
        = 6

Машина не умнее вас: она откладывает умножение, пока не дойдёт до дна, потом собирает столбик назад.

Цикл или рекурсия

Ряд в ширину — цикл. Вложенность — рекурсия

  • сумма зарплат за 12 месяцев — цикл;
  • формула со скобками «( … ( … ) … )» — рекурсия;
  • обход папок: папка внутри папки — рекурсия;
  • шашка прыгнула и может прыгнуть ещё — рекурсия.

Многое можно и циклом, и рекурсией. Выбирайте то, что совпадает с определением на бумаге.

Лабораторная 2

Скобка — подзадача того же калькулятора

скобка открывается один час плюс десять минут скобка закрывается умножить на два

Сначала тем же calc считаете внутренность, потом умножаете. Это рекурсивный спуск, не eval.

Лабораторная 4

Цепочка и луч — «шаг, и снова то же»

  • шашки: взяли, стоите на новой клетке, ищете следующее взятие;
  • реверси: идёте в одном направлении, пока ваши фишки не замкнули ряд;
  • сянци, амазонки: клетка, следующая клетка, следующая — пока не край или барьер.

В задании это прямо требуется рекурсией: чтобы на защите был один рассказ, а не 40 координат вручную.

Ошибки

Три способа сломать определение

  • нет базового случая — как ряд без a1;
  • шаг не уменьшает задачу — вечный цикл под другим именем;
  • слишком глубоко (тысячи вызовов) — тогда определение лучше развернуть в цикл.
Как объяснять

На защите три предложения

1. Что является «меньшим» экземпляром задачи.
2. Где дно.
3. Как из ответа меньшего собирается ответ текущего.

Если это говорится уверенно, код почти не смотрят. Если нет — смотрят очень внимательно.

Семестр целиком

Одна линия

Сначала коробки и присваивание. Потом повтор шага в ряд — цикл. Потом повтор шага внутрь — рекурсия.

Лабораторные — не четыре разные дисциплины. Это четыре сюжета, на которых эти две конструкции становятся привычкой.
