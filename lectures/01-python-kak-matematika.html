От бланка ЕГЭ
к Python

Сначала решение как на экзамене. Потом те же шаги — в коде.

Как читать эту лекцию

Три колонки у каждой задачи

  • условие — как в части с кратким ответом;
  • бланк — выкладка, которую вы отдали бы проверяющему;
  • Python — те же равенства и те же шаги, сверху вниз.

Язык ничего не придумывает. Он запрещает пропустить строку и посчитать «в уме».

Главная ловушка

Знак «=» — не одно и то же

На бланке ЕГЭ

x = 5 — утверждение: левая часть равна правой. Можно читать справа налево.

В Python

x = 5 — приказ: посчитать правую часть и положить результат в x.

Проверка равенства пишется ==. Иначе путаете уравнение и переписывание значения.

Почему x = x + 1 не бред

Это не уравнение. Это следующий член

В алгебре «x = x + 1» решений нет. В программе это смена записи:

взять старое a → прибавить d → записать снова в a.

a = 5
d = 3
a = a + d
# теперь a == 8, как a₂ при a₁ = 5

Старое значение после этой строки больше не существует. Имя одно.

Б-часть · 1

Степени и четыре действия

Найдите значение выражения:

(210 · 54) / (27 · 5)

На бланке сокращаем показатели:

210−7 · 54−1 = 23 · 53 = 8 · 125 = 1000

Б-часть · 1

Те же шаги в Python

num = 2**10 * 5**4
den = 2**7 * 5
answer = num // den
print(answer)   # 1000

** — степень, // — деление нацело, когда ответ целый. Можно писать и /, тогда получится 1000.0.

Б-часть · 2

Линейное уравнение

Решите уравнение 3(x + 4) = 5x − 2.

Бланк

3x + 12 = 5x − 2
12 + 2 = 5x − 3x
14 = 2x
x = 7

Python

left = 12 + 2
coeff = 5 - 3
x = left / coeff
print(x)   # 7.0
Б-часть · 3

Процент — это умножение

Найдите 12% от числа 250.

Бланк

250 · 12 / 100 = 30

Python

value = 250
p = 12
answer = value * p / 100
print(answer)   # 30.0

Никакой новой операции. Процент — запись дроби со знаменателем 100.

Б-часть · 4

Квадратное уравнение, наименьший корень

Найдите наименьший корень уравнения x² − 9x + 20 = 0.

Бланк

D = 81 − 80 = 1
x = (9 ± 1) / 2
x₁ = 5, x₂ = 4
ответ: 4

Python

a, b, c = 1, -9, 20
D = b**2 - 4*a*c
x1 = (-b - D**0.5) / (2*a)
x2 = (-b + D**0.5) / (2*a)
print(min(x1, x2))   # 4.0
Б-часть · 5

Член арифметической прогрессии

В прогрессии a1 = 5, d = 3. Найдите a12.

Бланк

an = a1 + (n − 1)d
a12 = 5 + 11 · 3 = 38

Python

a1, d, n = 5, 3, 12
an = a1 + (n - 1) * d
print(an)   # 38

Формула одна. Имена в коде — те же буквы, что на полях черновика.

Зачем перебор

Иногда проще перебрать, чем искать формулу

На ЕГЭ вы сворачиваете в P(n, k) или C(n, k). В Python можно пройти все подходящие наборы и посчитать, сколько их вышло.

Если вариантов мало (цифры, числа до сотни, пары из шести) — «в лоб» честнее, чем ошибиться в формуле.

Цикл здесь — только счётчик. Подробно циклы будут на следующей лекции.

Комбинаторика · 1

Трёхзначные из {1, 2, 3, 4} без повторений

Сколько таких чисел?

4 · 3 · 2 = 24

Первая цифра — 4 выбора, вторая — 3 оставшихся, третья — 2.

Комбинаторика · 1

Тот же 24 — перебором

count = 0
for a in range(1, 5):
    for b in range(1, 5):
        for c in range(1, 5):
            if len({a, b, c}) == 3:
                count = count + 1
print(count)   # 24

Три вложенных прохода по цифрам. Множество из трёх элементов — все цифры разные.

Комбинаторика · 2

Делятся на 3 или на 5

Сколько натуральных чисел от 1 до 40 делятся на 3 или на 5?

Бланк

|A ∪ B| = |A| + |B| − |A ∩ B|
⌊40/3⌋ + ⌊40/5⌋ − ⌊40/15⌋
13 + 8 − 2 = 19

В лоб

n = 0
for k in range(1, 41):
    if k % 3 == 0 or k % 5 == 0:
        n = n + 1
print(n)   # 19
Комбинаторика · 3

Выбрать двоих из шести

Сколькими способами выбрать 2 различных предмета из 6?

Бланк

C(6, 2) = 6! / (2! · 4!)
= 15

В лоб

n = 0
for i in range(1, 7):
    for j in range(i + 1, 7):
        n = n + 1
print(n)   # 15

j начинается после i — чтобы не считать пару дважды и не брать предмет сам с собой.

Функции

f(x) — формула с именем

f(x) = x² − 6x + 8

def f(x):
    return x**2 - 6*x + 8

Аргумент — то, что подставляете. return — то, что обвели в рамку в конце решения.

Функции

Подставить число — посчитать значение

Найдите f(0), f(2), f(5).

Бланк

f(0) = 8
f(2) = 4 − 12 + 8 = 0
f(5) = 25 − 30 + 8 = 3

Python

print(f(0))   # 8
print(f(2))   # 0
print(f(5))   # 3
Функции

Корни — где график пересекает ось x

Решите f(x) = 0, то есть x² − 6x + 8 = 0.

(x − 2)(x − 4) = 0  ⇒  x = 2 и x = 4

for x in range(0, 9):
    if f(x) == 0:
        print(x)

Формула даёт оба корня сразу. Перебор целых x на отрезке — проверка: график правда проходит через эти точки.

Функции

Пересечение двух графиков

Найдите точку пересечения прямых y = x + 1 и y = 2x − 3.

Бланк

x + 1 = 2x − 3
1 + 3 = 2x − x
x = 4, y = 5

В лоб по целым x

for x in range(-10, 11):
    if x + 1 == 2*x - 3:
        print(x, x + 1)
# 4 5
Типы

Число, текст и дата — разные вещи

  • 7 и 7.0 — число (целое и с дробной частью);
  • "7" — текст, даже если внутри цифра;
  • дата — тройка (год, месяц, день), не одно число.

Складывать можно однотипное. "12" + "3" даст "123", а не 15. Это не Excel и не «ячейка» — просто разные виды значений.

Строки

Текст — последовательность символов

Как число состоит из цифр, слово состоит из букв. Нумерация с нуля.

s = "математика"
s[0]      # 'м'
s[-1]     # 'а'
s[0:4]    # 'мате'
len(s)    # 10

s[a:b] — срез: от позиции a до b, правый край не входит.

Строки

Сумма цифр числа

Найдите сумму цифр числа 2026.

Бланк

2 + 0 + 2 + 6 = 10

Python

s = "2026"
total = 0
for ch in s:
    total = total + int(ch)
print(total)   # 10

int(ch) переводит символ-цифру в число, иначе сложите тексты.

Строки

Разворот и палиндром

word = "шалаш"
word[::-1]              # 'шалаш'
word == word[::-1]      # True

Срез [::-1] идёт с конца. Если слово совпало с разворотом — палиндром.

То же для числа: записали как строку, развернули, сравнили.

Строки

Найти, посчитать, заменить

t = "три плюс три равно шесть"
t.find("плюс")       # 4  — позиция, или -1 если нет
t.count("три")       # 2
t.replace("три", "3")
# '3 плюс 3 равно шесть'

Это не формулы ЕГЭ. Это разбор текста, когда условие пришло словами, а не одним числом.

Дата и время

Дата — год, месяц, день

from datetime import date, timedelta

start = date(2026, 9, 1)
end = date(2026, 12, 31)
print(start.year, start.month, start.day)

Не считайте дни «на пальцах» и не храните дату одной строкой, если нужно вычитать. Для этого есть date.

Дата и время

Сколько дней между датами

От 1 сентября 2026 до 31 декабря 2026.

delta = end - start
print(delta.days)   # 121

Разность двух дат — не дата, а промежуток. У него поле days.

Дата и время

Прибавить дни

exam = date(2026, 6, 15)
print(exam + timedelta(days=14))   # 2026-06-29
print(exam.weekday())              # 0 — понедельник

weekday(): понедельник = 0, воскресенье = 6. timedelta — сдвиг на заданное число дней (или часов, если это дата-время).

Дата и время

Текст превратить в дату

from datetime import datetime

raw = "15.06.2026"
d = datetime.strptime(raw, "%d.%m.%Y").date()
print(d)                 # 2026-06-15
print(d.strftime("%A"))  # Monday

Шаблон %d.%m.%Y должен совпасть со строкой. Иначе Python не угадает, где день, а где месяц.

Как читать программу

После каждой строки — что лежит в именах

  • какие имена изменились;
  • это ещё то же число, что на бланке, или уже другое;
  • если запутались — задача слишком длинная: разрежьте на функции-формулы.
