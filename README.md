# Практикум по программированию (ЭлКом, 1 курс, 1 семестр)

Это **базовый репозиторий курса**: задания, БРС, лекции и правила сдачи.  
Сюда **не нужно** делать форк и не нужно класть свой код.

Студент работает в форке **репозитория своей группы** — туда кладутся рыбы лабораторных и `student.json`. Проверки и веб-интерфейс живут отдельно, не в студенческих репозиториях.

## Сдача (кратко)

1. Форк **репозитория своей группы** (таблица выше), не этого.
2. В форке заполнить [`student.json`](student.json).
3. Код и тесты — в `Nlab/main.py` и `Nlab/test_main.py`, ветка `master`.
4. Из корня форка: `python3 Nlab/main.py` и `pytest`. Файл `.env` в git не класть: иначе работу не смотрят (ломает скрипты проверки).
5. На паре отметиться в [таблице посещаемости](https://docs.google.com/spreadsheets/d/1ZNWjld_zW6jlusZ-l1d5UQWeeBlzELPQYvSDdUAiWmo/edit?gid=671940646#gid=671940646) (лист своей группы) и защитить работу лично.

Полный текст, схема приёма и плагиат — в [ORGANIZATION.md](ORGANIZATION.md) и в README группового репозитория.
